== Requirements

* Android `minSdk` 26 (Android 8.0) or later.
* JUnit 4: `ConditionalIgnoreRule` is a JUnit 4 `MethodRule`.
* The library is compiled against SDK 36 with Java/Kotlin JVM target 17. It depends on `kotlin-reflect` and
  `androidx.test.espresso:espresso-core`, which Gradle resolves transitively.

== Gradle (Kotlin DSL)

Make sure `mavenCentral()` is among your repositories (in `settings.gradle.kts`):

[source,kotlin]
----
dependencyResolutionManagement {
    repositories {
        google()
        mavenCentral()
    }
}
----

Then add the dependency to the test source sets of your module's `build.gradle.kts`. The reflection helpers work in
local unit tests; the conditional-ignore rule and the gesture helpers are meant for instrumented tests:

[source,kotlin]
----
dependencies {
    // reflection helpers in local unit tests
    testImplementation("com.irurueta:irurueta-android-test-utils:1.3.2")

    // every utility in instrumented tests
    androidTestImplementation("com.irurueta:irurueta-android-test-utils:1.3.2")
}
----
